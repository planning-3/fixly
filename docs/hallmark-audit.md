## hallmark가 본 fixly (4줄 요약)

1. **용도**: 관리자·팀장이 리뷰·VOC를 팀 티켓으로 처리하는 업무 도구
2. **잘된 점(유지)**: 색이 토큰으로 관리되고 라이트·다크 모드 지원, 표 중심의 촘촘한 정보, 통계 카드마다 "기준" 문구
3. **AI가 만든 티**: `A · B · C` 가운뎃점 이어 붙이기가 앱 전체에, ⚠·↻ 기호를 아이콘 대신 사용, 연한 회색 글씨가 많음
4. **실제 문제**: 연한 회색 글씨(`--faint`) 대비 2.64:1(기준 4.5:1), 다크 모드 긴급 배지 흰 글씨 2.53:1
